# 38 — Glossary

This is the authoritative glossary for terminology used across the le-graph-ql documentation. Terms are listed alphabetically within each file and cross-referenced to the sections where they are covered in depth. To contribute: open a PR adding the term in alphabetical order within the appropriate file, following the established format (`**Term** — definition. *See also:* related terms. *Covered in depth:* Section X`).
